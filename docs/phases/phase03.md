# Phase 03 — Public Testnet

**Status: not yet started.**

The chain opens to outside participants for the first time.

## What this phase covers

This is where the bootstrapping model already decided in the design doc gets exercised for real: registrations go live from block 1, flagged testnet-grade until a minimum independent validator count is reached (likely 3+ validators across 2+ countries, exact number TBD). Confidence in the network grows as the validator set grows — there's no separate "flip the switch" moment.

Brock runs the first nodes, the same way Satoshi ran Bitcoin's first nodes — no special allocation, same rules as everyone else. Others join as the protocol qualifies them, with no permission required.

Brock still holds admin keys through this entire phase — nothing here changes that. The admin-key period doesn't end until Phase 05.

## What to expect

Real registrations, real usage patterns, and the first chance to see whether Phase 02's calibrated parameters (scoring curves, hub thresholds) hold up against genuine outside behavior instead of internal testing. This phase is likely to surface design gaps that Phase 00 has to go back and address — that's expected, not a failure of either phase.
