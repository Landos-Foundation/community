# Landos Roadmap: Project Phases

Landos moves through phases, not a fixed calendar. A phase ends when its purpose is served, not on a date decided in advance — the same principle behind the protocol's own staged entry model (design doc Section 13.1): readiness matters more than schedule.

These aren't strict gates. Phase 00 keeps running underneath every later phase. Phase 01's paper processes may keep proving useful for edge cases even once Phase 02 code exists. This is a map of what has to happen, roughly in what order — not a schedule.
