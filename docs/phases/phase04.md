# Phase 04 — Mainnet / Genesis

**Status: not yet started.**

The genesis block locks in.

## What this phase covers

Everything the design doc's Genesis Block section (18) specifies gets written permanently at launch: the 1,489,000,000 LOS supply (no pre-mine, no foundation allocation), the founding statement, the core principle that land acquired by force is not recognized, and the governance rules that will eventually take over.

Land claims carry real weight for the first time — this is the actual system, not a testnet or a paper stand-in.

## The admin-key countdown

Genesis also starts the countdown toward the governance activation block — a hard-coded block height equivalent to roughly a year of block production (calibrated against Bitcoin's block 32,700 as a reference point, adjusted for Landos's block speed). Before that block, Brock holds admin keys and changes can move fast. Block height governs the transition, not calendar time, so it adjusts naturally to whenever mainnet actually launches.
