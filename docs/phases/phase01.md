# Phase 01 — Paper Testnet

**Status: in progress.**

Before any of the design becomes code, it gets walked through by hand.

## What this phase covers

This is where people actually use the rules — filing test claims, attesting to them, certifying them as a Land Witness, raising a contest, proposing and voting on a decision — using GitHub as the stand-in for the chain that doesn't exist yet.

Two systems currently run this phase:

- [Provisional Governance](../../governance/README.md) — practice decisions and votes, one-member-one-vote, GitHub Issues and pull requests standing in for signed on-chain votes.
- [Paper Testnet](../../testnet/README.md) — practice land claims, walking a fictional test parcel through the real staged entry model: Notice Period, Neighbor Quorum (or the Land Witness fallback), a written stand-in for Habitation tracking, and Land Witness Certification.

## Why this phase exists

Two reasons. It gives someone joining right now something real to do, not just documents to read. And it's the cheapest way to find out where the design's rules break down in practice — before any of it is locked into code that's expensive to change.

## What it isn't

Nothing filed in either system during this phase carries legal weight, and nothing is guaranteed to carry forward once the real chain exists. Test parcels are fictional or clearly-marked placeholders — never real property. See each system's own README for the full rules and honest limitations of its particular stand-in.
