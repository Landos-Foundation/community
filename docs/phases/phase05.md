# Phase 05 — Governance Activation

**Status: not yet started.**

Admin keys are permanently retired.

## What this phase covers

The governance activation block set at Genesis (Phase 04) is reached. From this point on, all changes require the full bicameral governance process (design doc Section 18.2) — no admin key exists to move faster than that, for Brock or anyone else.

## The two chambers

- **Token Holder Assembly** — quadratic voting, resists whale capture.
- **Community Hub Assembly** — one hub, one vote, resists geographic concentration.

Both must reach a two-thirds supermajority before a change takes effect, and even then a 90-day timelock applies before it does.

## What this replaces

[Provisional Governance](../../governance/README.md) — the Phase 01 stand-in — is fully retired at this point. Its one-member-one-vote, GitHub-based process was always temporary by design; this is the real system it was standing in for.
